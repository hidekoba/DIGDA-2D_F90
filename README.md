# DIGDA-2D
Two-dimensional model of the diagenesis and geochemistry of deep-sea sediments for assessing the impact of climate change (DIGDA model) 

## Structure

### Bound
This folder contains the boundary forcing files used at the sediment-water interface.
These files provide initial boundary conditions for the model, specifying inputs at the points where sediment and water interact.

### init
This folder includes scripts for creating initial conditions for the experiments.
Initial conditions set the starting values for all variables, defining the baseline state of the model at the beginning of the simulation.

### RUN
Contains the primary script(s) for running the experiment. 
These scripts are used to execute the model with specified parameters and boundary conditions.

### OUT
This folder is where the output files from each experiment are stored.
Output files include results generated by the model after each run, often in a format suitable for further analysis.

### analysis
This directory includes scripts for analyzing the experimental results stored in the `OUT` directory.
These analysis scripts help interpret the output data by performing calculations or generating visualizations relevant to the study.

### bin
Contains the executable files required to run the model.
These files are typically compiled binaries that the model uses to perform simulations based on specified configurations.

### lib
This folder contains library files that provide additional functions or utilities required by the model or other scripts.
These libraries can include external code dependencies necessary for the model to run properly.

### src
Holds the source code files for the model itself.
These files contain the core code that defines how the model operates, from numerical calculations to system interactions.
